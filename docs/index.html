HLS & M3U8 Documentation

HTTP Live Streaming (HLS) delivers audio and video as a playlist plus a sequence of media segments. An .m3u8 file is a UTF-8 playlist that tells a player which variants, tracks and segments to request. StreamPlay can play compatible HLS URLs and inspect their playlist structure.

Master playlist vs. media playlist

A master playlist describes available renditions, bitrates, resolutions and alternate audio or subtitle tracks. It points to one or more media playlists.

#EXTM3U
#EXT-X-VERSION:3
#EXT-X-STREAM-INF:BANDWIDTH=2500000,RESOLUTION=1280x720
720p/index.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=900000,RESOLUTION=640x360
360p/index.m3u8

A media playlist describes the media segments for one rendition.

#EXTM3U
#EXT-X-TARGETDURATION:6
#EXT-X-MEDIA-SEQUENCE:0
#EXTINF:6.0,
segment000.ts
#EXTINF:6.0,
segment001.ts
#EXT-X-ENDLIST

Common HLS tags

TagPurpose
#EXTM3UIdentifies an M3U playlist.
#EXT-X-STREAM-INFDeclares a variant stream and its bandwidth or resolution.
#EXTINFGives the duration and optional title for the next segment.
#EXT-X-TARGETDURATIONSets the maximum segment duration target.
#EXT-X-MEDIA-SEQUENCEIdentifies the sequence number of the first segment.
#EXT-X-ENDLISTIndicates that no more segments will be added to the playlist.
#EXT-X-KEYDescribes encryption information, such as AES-128 key retrieval.
#EXT-X-MAPIdentifies an initialization section, commonly used with fragmented MP4.
#EXT-X-MEDIADescribes alternate audio or subtitle renditions.
#EXT-X-DISCONTINUITYMarks a change in the media timeline or encoding parameters.

Segment formats

HLS commonly uses MPEG-TS segments (.ts) or fragmented MP4 segments (.m4s) with an initialization section. The playlist and segment MIME types, byte ranges and URL paths must be served correctly by the origin.

Adaptive bitrate streaming

A master playlist can offer multiple renditions. A compatible player selects a rendition based on bandwidth and playback conditions. StreamPlay's analyzer helps you inspect the variants advertised by the playlist; actual quality selection depends on the player engine and stream.

Encryption and DRM

#EXT-X-KEY can describe HLS encryption such as AES-128. This does not mean a browser player can bypass protected content. StreamPlay does not circumvent DRM, license servers, authentication or access controls.

CORS and browser playback

When the playlist or segments are hosted on another origin, the source server must allow the browser's cross-origin requests. A stream may work in a desktop media player but fail in a browser because the browser enforces CORS. Check the playlist response and segment responses, not just the HTML page.

Diagnose a playlist

  1. Open the StreamPlay player and paste the full HTTPS playlist URL.
  2. Use the playlist analyzer on the home page to inspect variants, tracks, segments and key tags.
  3. Open the browser Console and Network panel to identify CORS, HTTP status, MIME type or codec errors.

For common fixes, see the HLS playback guides and FAQ. The playback engine is based on hls.js.

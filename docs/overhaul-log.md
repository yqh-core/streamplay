# StreamPlay 改造记录（2026-11-18）

## 对标结论

复盘包把本站定为中文优先的存量产品（`MAINTAIN_LOCAL`），不把历史中文流量当成欧美需求，也不新开英文 SEO。页面语言保持中文。英文词条只维持既有 `locales/en.json` 与中文 key 对齐，没有新增 `/en/` 页面。

竞品参照：Bitmovin Stream Test、hls.js 演示、livepush、THEOplayer 测试页、m3u8player，以及复盘包点名的 hls.js / LivePlayer。差距矩阵里已有的是清单解析、变体/分片、嵌入和深链。缺的是稳定播放体验、可读的错误归因、音轨/字幕/码率、buffer / live edge / latency、DASH，以及播放历史。

本轮在现有页面上补了这些能力，没有新开 SEO 页，没有改分析埋点，没有部署。

Chrome 无头浏览器里核实到：

- Mux 多码率 HLS 出画（1280×720），画质保持自动，分片时间线画出 184p–1080p。
- Akamai Big Buck Bunny DASH 出画（3840×2160，10 档，自动）。
- `https://example.com/no-such-stream.m3u8` 给出「浏览器没有拿到清单」，并写出跨域、地址、https 三步。
- 分享面板生成指向 `play.digdevbox.com` 的 iframe，查询参数已编码。
- 播过的地址记入本机历史（计数为 1）。

没有在 Safari、Firefox 和真机上复验。直播边缘和引擎延迟的数字有代码，这次用的是点播样例，面板显示「点播」。DRM 明确不支持，也没有拿加密流去绕。

## 改动清单

- 首页改成播放工作台：地址、样例、深色播放器、质量 / 分片 / 清单 / 诊断 / 分享 / 历史。
- 质量面板：分辨率、码率、带宽、前方缓冲、丢帧；直播时显示距边缘和引擎延迟。带宽曲线超过 80 Mbps 显示「≥ 80 Mbps」，避免缓存把数字冲到几百 Mbps。
- 分片时间线：按画质上色，白线是播放头。
- 清单：m3u8 主清单/媒体清单，mpd 的 Representation 表。解析在 `js/stream-core.js`，Node 测试覆盖。
- 诊断：hls.js / dash.js 错误码对应原因和下一步。404、403、解析失败、编码不支持和 DRM 不再空转重试。
- DASH：本地 `libs/dash.all.min.js`（dash.js 4.7.4，BSD），只有 MPD 才加载。
- 分享链接、嵌入代码、本机历史、队列、字幕、A-B、画中画、全屏、续播都还在。滚动不再自动弹出小窗，避免挡住检查面板。
- 文案改成口语中文。隐私页改正三处不实说法：广告（页面有 AdSense）、本机历史、`?url=` 会出现在访问日志。版权页不再承诺服务器端下架。
- 门禁：`node --test scripts/test-stream-core.mjs` 已加入 `.github/workflows/verify.yml`。仓库没有 TypeScript，也没有打包步骤。

## 三轮复盘

### 第一轮

对照差距矩阵和页面实拍。

发现：手机上地址框被旧样式挤没；hls.js 1.7 的 `currentLevel` 在自动模式下返回正在播的档，界面误显示「手动锁定」；带宽估算被缓存冲到约 900 Mbps；续播条盖住控制条；小窗盖住诊断；缓冲 80 秒仍写「够播一小段」；同一次失败记了两条。

修复：地址栏样式压过旧规则；用 `autoLevelEnabled` 判断自动；带宽取分片中位数并封顶显示；续播改到画面上方；取消自动小窗；缓冲文案按秒数分档；同一种错误只留一条。

### 第二轮

再跑 Chrome：HLS 自动切换为真，DASH 4K 无报错，手机地址框宽 358px、高 48px，时间线有分片和画质图例，分享代码和历史计数正常。

发现：控制按钮被挤成竖排文字；空播放器在深色下是一块白；顶栏在窄屏被切掉。

修复：次要按钮收进「更多」，主控制条一行；空播放器铺黑底并加黑色 poster；顶栏允许换行。复拍后播放器控制条一行排开，深色页视频底为 `rgb(0, 0, 0)`。

### 第三轮

再对清单：没有新增 SEO 页；没有新分析事件，没有改身份或存储键的语义（`streamplay:recent` 仍是字符串数组）；媒体请求不去本站；没有部署、DNS、支付或对外发帖。错误建议覆盖矩阵里的跨域、编码、密钥/DRM、分片和缓冲。音轨切换和外部字幕的代码还在，这次没有用真实字幕地址点过。Safari / Firefox / 真机播放仍未测，不能写成已经超过竞品的用户体验。

About StreamPlay

StreamPlay is a browser-based player for compatible M3U8 / HLS live and on-demand streams, plus MP4 URLs supported by your browser. It is designed for quick playback tests, playlist inspection and practical troubleshooting without installing a desktop application.

What you can do

  • Play HLS live and video-on-demand streams when the source permits browser access.
  • Play MP4 and other formats supported by the browser's native media engine.
  • Inspect M3U8 master and media playlists, including variants, audio tracks, segments and key tags.
  • Generate a shareable player URL or iframe embed with the ?url= parameter.
  • See clear playback errors for network failures, CORS restrictions and unsupported formats.

How playback works

StreamPlay uses hls.js for browsers that need Media Source Extensions to play HLS. Browsers with native HLS support may use their built-in playback engine. MP4 playback uses the HTML5 <video> element. The browser, stream server, codecs and cross-origin response headers determine whether a particular URL can play.

Privacy by design

The stream URL you enter is requested by your browser directly from the host you specify. StreamPlay does not proxy, host, record or distribute the media. The website itself is hosted on Cloudflare Pages and uses Google AdSense; optional Google Analytics 4 loads only after you grant analytics consent. Read the Privacy Policy for details.

Technical stack

HLS enginehls.js, served from this site, plus native browser HLS where available
Media playbackHTML5 video and Media Source Extensions
ApplicationHTML, CSS and JavaScript
BackendNo media proxy or server-side transcoding

Important limitations

  • StreamPlay cannot bypass DRM, authentication, geo-restrictions, paywalls or access controls.
  • The source server must allow the browser to request the playlist and media segments, including appropriate CORS headers for cross-origin playback.
  • Codec support varies by browser and operating system. H.264 is broadly supported; HEVC/H.265 support is more limited.
  • StreamPlay does not download or record media.

For step-by-step help, see the playback guides and HLS documentation.

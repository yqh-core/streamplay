播放故障

请先按使用教程里的排查清单自行确认一遍，大多数「播不了」其实是这三件事：地址本身打不开、对方服务器不允许跨域、编码格式浏览器不支持。

确认后仍无法解决，请到 GitHub Issues 提交，并附上：

  • 播放地址（如涉及隐私可先做脱敏，说明是否为公开测试流）；
  • 浏览器与版本、操作系统；
  • 页面上显示的具体错误提示原文；
  • 浏览器开发者工具 Console 里的报错（如有）。

功能建议

想要多码率手动切换、倍速记忆、字幕支持、播放统计等功能，都可以在 Issues 提出。我们会按需求热度排期，但不承诺实现时间。

侵权投诉

本站不存储、不制作、不分发任何音视频内容，仅提供播放技术演示。如你是通过本站被播放的内容的权利人，认为相关播放行为侵犯了你的合法权益，请通过 Issues 联系我们并说明权属情况，我们会配合处理。

隐私与合规

涉及个人数据、删除请求或合规问询，请先阅读隐私政策，再通过 GitHub Issues 联系。

响应时间

本站由个人维护，非商业客服。我们通常在 1–7 个工作日内回复 GitHub Issues，不保证响应全部请求，也不提供电话与即时通讯支持。

关于 StreamPlay 流影

StreamPlay 流影用来在浏览器里播放并检查一条流。HLS、不带 DRM 的 DASH，以及 mp4 都可以。页面是静态的，没有自己的媒体服务器。

你能在这里做什么

  • 播放，并手动锁定画质，或让它按带宽自己切。
  • 看带宽、前方缓冲、丢帧，以及已经下载的分片时间线。
  • 把主清单和子清单展开成表；MPD 会列出 Representation。
  • 出错时读一段人话：原因是什么，下一步可以试什么。
  • 复制带时间点的链接，或生成 iframe。历史和队列只留在这台浏览器。

技术栈

播放内核 hls.js 1.7.3 与 dash.js 4.7.4，都放在本站，加上 HTML5 <video>
样式 原生 CSS（CSS 变量 + Flex 布局），无 UI 框架
脚本 原生 JavaScript，无 jQuery、无构建步骤
后端 无，纯静态站点

部署方式

  • 直接部署：把整个目录上传到任意静态服务器的网站根目录，访问 index.html 即可。
  • Nginx 示例：root /var/www/streamplay; 并确保 .m3u8、.ts 不被当作下载文件处理。
  • 本地预览：在本目录执行 python -m http.server 8080，浏览器打开 http://localhost:8080。

常见问题排查

诊断说浏览器没有拿到清单 多半是源站没返回 Access-Control-Allow-Origin。先用新标签打开地址：文本能开、播放器不行，就是跨域。需要在源站开，播放器绕不过去。
一直停在加载中 检查地址是否可直接访问（用浏览器新标签页打开该 m3u8），以及网络是否能直连到该域名。
黑屏但无报错 多为编码格式不受支持。播放器要求视频为 H.264 编码，H.265/HEVC 在多数浏览器中无法播放。
浏览器自动播放被拦截 这是浏览器的自动播放策略，属正常行为，点击播放器上的播放按钮即可。

M3U8 & HLS Player FAQ

Quick answers to common StreamPlay playback, playlist and embedding questions. For a step-by-step walkthrough, see the HLS playback guides.

What is an M3U8 URL?

An M3U8 URL points to an HLS playlist. The playlist describes a live or on-demand stream and the media segments a compatible player should request.

Why does a stream work in VLC but not in my browser?

Desktop players and browsers have different network and codec rules. A browser may block cross-origin requests without CORS headers, reject an unsupported codec, or be unable to access a protected stream.

How do I fix a CORS error?

The stream host must return suitable Access-Control-Allow-Origin headers for the playlist and every media segment or key request. CORS cannot be fixed from the player page; the stream server operator must configure it.

Does StreamPlay support MP4?

Yes. MP4 playback uses the browser's native HTML5 video support. The codecs inside the file must still be supported by that browser and device.

Does it support H.265 / HEVC?

Support depends on the browser, operating system and hardware. H.264 has broader browser support; HEVC/H.265 playback is not available in every browser.

Can StreamPlay play DRM-protected streams?

No. StreamPlay does not bypass DRM, license servers, authentication, paywalls or geographic restrictions.

Can I download or record a stream?

No. StreamPlay is a playback and playlist-inspection tool. It does not provide downloading or recording features.

How do I embed the player?

Use the player URL with an encoded stream URL, for example `https://play.digdevbox.com/?url=https%3A%2F%2Fexample.com%2Flive.m3u8`. The source must permit browser access, and you must have permission to play it.

Why does autoplay not start?

Browsers commonly block autoplay with sound. Start playback with the player controls, or use muted autoplay only where your browser and the page allow it.

Does StreamPlay store my stream URL?

The player requests the stream directly from your browser. Do not put credentials or private tokens in a URL: if you use the `?url=` embed parameter, that parameter is part of the page request and may appear in hosting request logs. See the Privacy Policy.

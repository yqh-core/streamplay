M3U8 & HLS Player Guide

This guide covers the common tasks people use StreamPlay for: testing an HLS URL, understanding a playlist, embedding a player and diagnosing browser playback errors.

1. Play an M3U8 or MP4 URL

  1. Open the StreamPlay player.
  2. Paste the complete HTTPS M3U8 or MP4 URL into the player input.
  3. Select Play. If playback fails, copy the exact error and check the browser Console and Network panels.

For HLS, use the master playlist URL when one is available. A media playlist URL may play a single rendition without alternate quality or audio tracks.

2. Embed StreamPlay on a website

StreamPlay supports a ?url= parameter for opening a supplied stream in the player. URL-encode the stream address before placing it in the iframe URL.

<iframe
  src="https://play.digdevbox.com/?url=https%3A%2F%2Fexample.com%2Flive.m3u8"
  title="HLS video player"
  width="100%"
  height="480"
  allow="autoplay; fullscreen; picture-in-picture"
  allowfullscreen
  loading="lazy">
</iframe>

Only embed streams you are authorized to use. The source host must permit requests from the browser; the iframe does not bypass CORS, authentication or DRM.

3. Diagnose CORS errors

  • Open the playlist URL directly in a new browser tab to confirm that it is reachable.
  • In DevTools → Network, inspect the playlist, segment and encryption-key requests.
  • Check that the source returns appropriate CORS headers on every cross-origin resource, not only the first playlist.
  • Ask the stream provider to configure CORS. A player page cannot override the browser's same-origin security policy.

4. Diagnose HTTP errors

  • 401 / 403: the server requires authentication or denies the request. Use an authorized URL; StreamPlay cannot bypass access controls.
  • 404: the playlist or one of its segment paths may have expired or moved.
  • 5xx: the source server or CDN may be unavailable.
  • Mixed content: an HTTPS page may not load an insecure HTTP stream. Use an HTTPS source where available.

5. Diagnose codec and autoplay issues

H.264 video with AAC audio is broadly supported. HEVC/H.265 and less common audio codecs vary by browser and device. Autoplay with sound is commonly blocked; press Play if playback does not start automatically.

6. Inspect the playlist

Use the M3U8 playlist analyzer on the home page to inspect variant streams, resolutions, bandwidth values, alternate audio tracks, segment URLs and encryption tags. Compare the master playlist with the media playlist requested by the player.

7. Generate a local HLS test stream

If you have a local video file and FFmpeg installed, you can create a simple VOD test playlist:

ffmpeg -i input.mp4 -c:v libx264 -c:a aac -f hls -hls_time 6 -hls_playlist_type vod output.m3u8

Serve the output directory over HTTP with correct MIME types and CORS headers before testing it in a browser.

For protocol details, see the HLS documentation. For quick answers, see the FAQ.

How to play an M3U8 URL

  1. Open StreamPlay and paste the full .m3u8 playlist URL into the address field.
  2. Select Play. If the stream is public and its origin permits cross-origin browser requests, playback should begin.
  3. For a multi-bitrate master playlist, inspect available variants and select a quality when supported.
  4. If playback fails, run the diagnostics and check the stream URL, origin response, CORS headers, codecs and browser support.

Why does an M3U8 stream fail in a browser?

Common causes include an expired signed URL, a playlist or segment returning an HTTP error, missing CORS headers, an unsupported codec, an invalid media playlist, or a stream that requires credentials the browser does not have. A successful playlist request does not guarantee every segment is reachable. Check the playlist and segment responses at the source.

Important: CORS is enforced by the browser. StreamPlay can help identify a cross-origin problem, but it cannot bypass the policy configured by the stream host.

Can I embed an HLS player on my website?

Use StreamPlay's embed generator to configure the stream and preview the iframe. Always confirm that you have permission to embed the content and that the origin allows the required requests. Do not expose private stream tokens in public pages.

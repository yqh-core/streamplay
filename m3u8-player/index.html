What is an M3U8 or HLS stream?

HTTP Live Streaming (HLS) uses a playlist, commonly an M3U8 file, to describe media segments and optional variant streams. A master playlist can advertise multiple resolutions and bitrates; a media playlist lists the segments for a particular rendition.

How to play an HLS stream

  1. Open the StreamPlay player.
  2. Paste a stream URL ending in .m3u8, or enter a compatible MP4 URL.
  3. Select Play and allow the browser to load the stream from its source.
  4. If playback fails, use the diagnostics and check the source server's CORS policy, URL availability, codec support and encryption requirements.

Inspect a playlist before playback

The M3U8 analyzer can inspect a playlist when the source allows browser access. A master playlist may expose available variants, resolution and bandwidth metadata; a media playlist may expose segment counts, durations and encryption markers. Analysis is not a way to bypass access controls or DRM.

Common playback problems

  • CORS: the media host must allow requests from the page's origin for browser-based playlist inspection and some playback paths.
  • Unsupported codecs: browser and device support varies. A valid playlist does not guarantee that every media codec can be decoded.
  • Expired or protected URLs: signed URLs may expire, and DRM-protected streams require their authorized playback workflow.
  • Mixed content or network errors: check HTTPS requirements, redirects and whether the media host is reachable.

Generate an iframe embed

Use the embed builder in StreamPlay to configure the source URL, dimensions and supported playback options, then copy the generated iframe snippet into a page you control. Browser autoplay policies commonly require muted playback and may still vary by browser.

Privacy and stream delivery

Playback requests are made by your browser to the media source; StreamPlay does not host the video files. Your browser's network connection to the media origin is necessary for playback. Only use stream URLs that you are authorized to access.

Frequently asked questions

Does StreamPlay support live HLS?

It can play compatible live and on-demand HLS streams when the browser, codecs, source URL and server CORS configuration permit playback.

Why can a stream play elsewhere but not in my browser?

Different players may use different network paths, native playback support or authorization mechanisms. Check CORS, codec compatibility, URL expiry and source-server restrictions.

Can it play DRM-protected content?

The playlist analyzer may identify encryption markers, but it does not bypass DRM or access restrictions. Use the content provider's authorized player and license flow.

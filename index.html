      How to play a stream

      1. Get a stream URL — Paste an M3U8 / HLS URL into the field, or select one of the sample streams above.
      2. Select Play — Select the blue Play button or press Enter Enter.
      3. Watch — Once playback starts, use the controls to pause, adjust volume, seek and enter fullscreen. Landscape mode is recommended on phones.

      Tip: If the player stays on “Loading” or reports an error, the URL may be unavailable or the source may block cross-origin requests. Open the URL in a new browser tab first; if it cannot be reached there, the player cannot load it either.

                StreamPlay is a browser-based online player built on HTML5 <video> and the open-source library
                hls.js
                It plays compatible .m3u8 HTTP Live Streaming (HLS) streams and browser-native formats such as MP4 without a browser plugin or desktop client. hls.js transmuxes supported MPEG-2 transport stream and AAC/MP3 media into ISO BMFF (MP4) segments for playback through the browser's Media Source Extensions API, with Web Workers handling background work. Actual playback depends on the source URL, CORS policy, codecs and browser support.
            
      

            
      What is an M3U8 file?
      
            
      
                Files with the extension M3U8
                are UTF-8 encoded playlist files. They are plain-text playlists that tell a media player where to find audio and video resources.
            
      
            
      
                For example, an M3U8 file can point to an internet radio stream or serve as a playlist for a personal collection of music or videos.
            
      
            
      
                In either case, the playlist points the player to the media resources. An M3U8 file is a convenient way to organize and replay a set of streams.
            
      
            
      
                Entries can use absolute paths, relative paths or full URLs to reference media files. Other lines can appear as comments that describe the playlist.
            
      
            
      
                M3U8 playlists are used for audio and video streaming. They reference online media resources and are supported by many modern media players.
            
      
        
      

        
        
      
            
      Frequently asked questions
      
            
      
                Which video formats are supported?
                
      The player supports M3U8 / HLS live and on-demand streams, plus browser-native formats such as MP4, WebM and Ogg. HLS is handled by hls.js; native formats use the browser's built-in player.
      
            
      
            
      
                Why does a video fail to load or keep buffering?
                
      The URL may be unavailable, or the source server may block cross-origin requests (CORS). Try opening the URL in a new browser tab to check that it is reachable.
      
            
      
            
      
                Are my stream URLs uploaded or stored?
                
      Playback runs in your browser and the video stream does not pass through our server. Recent URLs are stored only in this browser and can be cleared at any time.
      
            
      
            
      
                Can I change playback speed and quality?
                
      Yes. The controls offer six speeds from 0.5× to 2×. For multi-bitrate HLS streams, select a rendition from the quality menu or use automatic switching.
      
            
      
            
      
                How do I load subtitles?
                
      Paste a .vtt or .srt URL into the Subtitles tool, load it, then select the track in the player menu. Cross-origin subtitles require CORS permission.
      
            
      
            
      
                Can I resume playback or share a timestamp?
                
      Yes. Playback progress is stored only in this browser. Reopening the same URL offers a resume option, and the share control copies a timestamped URL (?url=URL&t=seconds).
      
            
      
            
      
                How can I troubleshoot playback or view statistics?
                
      Select the diagnostics control to check MSE / hls.js support, H.264 / WebM decoding, network state, URL reachability and CORS. Select statistics to view resolution, codec, estimated bandwidth, buffer health and dropped frames.
      
            
      
            
      
                Can I queue multiple streams or keep watching while scrolling?
                
      Yes. Add URLs to the queue and enable Autoplay next to advance automatically. Use Previous / Next to navigate or Repeat current stream to loop one item. The mini-player floats while scrolling; use Restore or Close to control it.
      
            
      
            
      
                How do I inspect available renditions and audio tracks in an M3U8 playlist?
                
      Paste a URL into the M3U8 Playlist Analyzer and select Analyze. A master playlist lists variants, resolutions, bandwidth, codecs, audio tracks and subtitle groups. A media playlist reports segment count, duration, live / on-demand state and encryption markers. Analysis runs locally and requires CORS permission. See /guides#analyzer。
      
            
      
            
      
                How do I embed the player on my website?
                
      Use the Embed Builder to enter a stream URL, dimensions, start time and autoplay options. Preview the result and copy the iframe code; it points to play.digdevbox.com. Most browsers allow autoplay only when muted.

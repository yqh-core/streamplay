    怎么播放？三步就够了

    1. 拿到地址 —— 在输入框里粘贴你的 m3u8 / HLS 播放链接，或直接点上面的「测试流」按钮自动填入。
    2. 点播放 —— 点右侧蓝色「播放」按钮，或直接按 Enter 回车。
    3. 观看 —— 画面出现后，鼠标移到播放器上，用底部控制条暂停、调音量、拖进度、全屏。手机浏览器横屏观看效果更好。

    提示：如果一直停在「正在加载」或提示失败，多半是地址本身打不开，或对方服务器不允许跨域访问。 可以先用浏览器新标签页直接打开这个地址验证一下 —— 能打开，播放器才能播。

    <iframe src="https://你的域名/?url=https://example.com/index.m3u8&t=90" width="100%" height="480" frameborder="0" allowfullscreen></iframe>

    StreamPlay 流影是一款纯前端的在线播放器，基于 HTML5 <video> 与开源 hls.js 实现。它无需安装任何浏览器插件或客户端，打开网页即可播放 .m3u8 HTTP Live Streaming (HLS) 流媒体，同时也支持浏览器原生的 mp4 等格式。其原理是把 MPEG-2 传输流与 AAC/MP3 音频流 转封装为 ISO BMFF (MP4) 分片后交给浏览器播放，并借助 Web Worker 异步完成转码，因此在 现代浏览器中可以流畅播放直播与点播内容。

    什么是 m3u8 文件？

    扩展名为 M3U8 的文件是一种 UTF-8 编码的播放列表文件。它是纯文本文件，音视频播放器可以用它来描述媒体文件的位置。

    例如，一个 M3U8 文件可能指向互联网电台的在线音频流；另一个文件可能是在本地创建的，用于为你的个人音乐或视频系列建立播放列表。

    无论哪种方式，效果都相同：打开文件即可快速开始播放列表所指向的内容。如果你希望反复播放同一批内容，制作一个 M3U8 文件就是最便捷的方式。

    文件内部的条目可以使用绝对路径、相对路径或完整 URL 来指向具体的媒体文件，甚至整个媒体文件夹；文件中的其他信息则可以作为描述内容的注释。

    M3U8 最初是为播放 MP3 等音频文件而设计，如今越来越多的场景用它来承载视频播放列表，它同样可以指定在线流媒体的音视频源。目前主流的播放器与软件大多支持 M3U8 格式。

    常见问题

    支持哪些视频格式？

    支持 m3u8 / HLS（直播与点播）以及浏览器原生的 mp4、webm、ogg 等格式。HLS 由 hls.js 解析，mp4 等走浏览器原生播放，无需安装插件。

    为什么视频加载失败或一直转圈？

    多半是地址本身打不开，或对方服务器不允许跨域访问（CORS）。可以先在浏览器新标签页直接打开该地址验证——能打开，播放器才能播。

    我的播放地址会被上传或保存吗？

    播放是纯前端行为，视频流不经过本站服务器。「最近播放」只存在你自己浏览器的 localStorage 里，不会上传，可随时清空。

    可以调整播放速度和画质吗？

    可以。控制条提供 0.5× 到 2× 六档速度；对于多码率 HLS 流，画质菜单会列出各档分辨率，可手动锁定或自动切换。

    如何加载字幕？

    在「字幕」工具中粘贴 .vtt 或 .srt 字幕地址并加载，然后在字幕菜单中选择轨道。跨域字幕需要对方服务器允许 CORS。

    能记住播放进度或分享指定时间点吗？

    能。播放进度只存在本机浏览器，再次打开同一地址会提示「继续播放」；点控制条 🔗 按钮可复制带当前时间点的分享链接（?url=地址&t=秒数），对方打开即从该时间点开始。

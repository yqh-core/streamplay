      How to play an HLS stream in three steps

      1. Get a stream URL — Paste an M3U8 / HLS playback URL into the input field, or select one of the sample streams above.
      2. Select Play — Select the Play button or press Enter.
      3. Watch and control playback — Move the pointer over the player to pause, adjust volume, seek or enter fullscreen. On phones, landscape orientation may provide a better viewing experience.

      If the player stays on Loading or reports an error, the URL may be unavailable or the media host may block cross-origin requests. Try opening the stream URL in a new browser tab first. A reachable URL is a useful first check, but playback can still depend on CORS, codecs and browser support.

      StreamPlay is a browser-based player built with the HTML5 <video> element and the open-source hls.js library. It plays compatible HTTP Live Streaming (HLS) sources, commonly referenced by an .m3u8 playlist, as well as browser-supported MP4 and other media formats. Your browser retrieves media from the source host; StreamPlay does not host video files.
      
            
      What is an M3U8 file?
      
            
      An M3U8 file is a UTF-8 text playlist that describes media resources and how a player should request them. It may reference individual media segments or a master playlist that points to multiple stream variants.
      
            
      A master playlist can describe several resolutions and bitrates so a compatible player can select a rendition based on device and network conditions. A media playlist lists the segments for one rendition and may describe timing, live-window behavior and encryption metadata.
      
            
      Playlist entries can use absolute URLs, relative paths or full URLs to reference media segments. The playlist may also include comments and metadata that help describe the stream.
      
            
      M3U8 is widely used with HLS for live and on-demand video. A valid playlist does not guarantee playback: the browser, codecs, source availability, authorization and CORS policy must also permit the request.
      
        
      

                
        
      
            
      Frequently asked questions
      
            
      Which media formats does StreamPlay support?
      StreamPlay supports compatible M3U8 / HLS live and on-demand streams, plus browser-supported MP4, WebM and Ogg media. HLS playback uses hls.js where required; native formats use the browser's media support.
      
            
      Why does a stream fail to load or keep buffering?
      The URL may be unavailable, expired or protected, or the media host may block cross-origin requests (CORS). Codec support and browser capabilities also vary. Check the URL, CORS response headers and the playback diagnostics.
      
            
      Are my stream URLs uploaded or stored?
      Playback requests go from your browser to the media source; StreamPlay does not host the video files. Recent URLs and playback progress are stored locally in this browser and are not uploaded to this site. You can clear the local history at any time.
      
            
      Can I change playback speed and video quality?
      Yes. The player offers speed settings from 0.5× to 2×. For multi-bitrate HLS streams, the quality menu can show available renditions for manual selection or adaptive switching.
      
            
      How do I load subtitles?
      Enter a VTT or SRT subtitle URL in the Subtitles tool and load it, then select the track in the player's subtitle menu. The subtitle host must allow cross-origin requests when the browser requires them.
      
            
      Can StreamPlay remember playback progress or share a timestamp?
      Playback progress is stored locally in this browser. When you reopen the same URL, the player can offer to resume. Use the share control to copy a link with a timestamp so another person can open the stream at that position, subject to the source URL's access rules.
      
            
      How can I diagnose playback problems or inspect playback statistics?
      Open Playback diagnostics to check MSE / hls.js support, H.264 and WebM decoding capability, network state and URL reachability, including CORS-related checks. The statistics panel can show resolution, codec, estimated bandwidth, buffer health and dropped frames when the browser exposes those values.
      
            
      Can I play multiple streams in sequence or keep the player visible while scrolling?
      Yes. Add URLs to the Playback queue and enable Autoplay next to advance automatically. You can also move to the previous or next item, repeat the current stream, or use the floating mini-player while scrolling.
      
            
      How do I inspect available renditions and audio tracks in an M3U8 playlist?
      Yes. Paste a URL into the M3U8 playlist analyzer. A master playlist can expose variants, resolution, bandwidth, codecs, audio and subtitle groups. A media playlist can expose segment counts, durations, live or on-demand state and encryption markers. Analysis runs locally and requires the source host to allow CORS. It does not bypass DRM or access controls. See the playlist analyzer guide.
      
            
      How do I embed the player on my own website?
      Use the iframe embed builder to enter a stream URL, dimensions, start time and autoplay options. Preview the result and copy the iframe code. The embed points to play.digdevbox.com and uses a URL parameter to load your stream. Most browsers restrict autoplay unless the video is muted, and behavior varies by browser.

StreamPlay 流影是一款纯前端的在线播放器，基于 HTML5 <video> 与开源 hls.js 实现。它无需安装任何浏览器插件或客户端，打开网页即可播放 .m3u8 HTTP Live Streaming (HLS) 流媒体，同时也支持浏览器原生的 mp4 等格式。其原理是把 MPEG-2 传输流与 AAC/MP3 音频流 转封装为 ISO BMFF (MP4) 分片后交给浏览器播放，并借助 Web Worker 异步完成转码，因此在 现代浏览器中可以流畅播放直播与点播内容。

什么是 m3u8 文件？

扩展名为 M3U8 的文件是一种 UTF-8 编码的播放列表文件。它是纯文本文件，音视频播放器可以用它来描述媒体文件的位置。

例如，一个 M3U8 文件可能指向互联网电台的在线音频流；另一个文件可能是在本地创建的，用于为你的个人音乐或视频系列建立播放列表。

无论哪种方式，效果都相同：打开文件即可快速开始播放列表所指向的内容。如果你希望反复播放同一批内容，制作一个 M3U8 文件就是最便捷的方式。

文件内部的条目可以使用绝对路径、相对路径或完整 URL 来指向具体的媒体文件，甚至整个媒体文件夹；文件中的其他信息则可以作为描述内容的注释。

M3U8 最初是为播放 MP3 等音频文件而设计，如今越来越多的场景用它来承载视频播放列表，它同样可以指定在线流媒体的音视频源。目前主流的播放器与软件大多支持 M3U8 格式。
